# ProblemStatement3

Conditional GAN that generates MNIST digits for a chosen class, with a Streamlit demo.

Conditional GAN trained on MNIST. `trained_generator.pth` is included, so the Streamlit demo runs without retraining.

## Stack

- Python
- Streamlit
- PyTorch

## Getting started

```bash
pip install -r requirements.txt
python app.py
```
